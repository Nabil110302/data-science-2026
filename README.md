## Cara Menjalankan Notebook

Notebook dapat dijalankan melalui Google Colab:

1. Buka file notebook yang ingin dijalankan.
2. Upload ke Google Colab.
3. Klik **Runtime > Run all**.
4. Pastikan seluruh cell berjalan tanpa error dan output tampil.

Jika dijalankan secara lokal, instal library berikut:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn tensorflow mlxtend requests gdown
```
